# Python Finance Tracker

A beginner-friendly, command-line finance tracker built with Python.

## Features

- Add income to the current balance
- Record expenses
- Prevent expenses that exceed the current balance
- View the current balance
- Interactive menu-based interface

## Technologies Used

- Python
- Functions
- Conditional statements
- While loops
- User input and basic error handling

## How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run:

   `python main.py`

## Future Improvements

- Transaction history
- Income and expense categories
- Persistent storage using JSON
- Monthly spending summaries
